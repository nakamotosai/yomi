# YOMI | Reader 🇯🇵

**YOMI (読み)** is a modern, interactive Japanese reading assistant designed to help learners analyze, read, and understand Japanese text.

## ✨ 核心機能 (Core Features)

### 1. 📝 スマートテキスト分析 (Smart Text Analysis)
- **自動形態素解析**: `Kuroshiro` & `Kuromoji` を使用して、日本語の文章を単語単位（トークン）に自動分解します。
- **フリガナ付与**: 漢字に自動で読み仮名を振ります。
- **文章構造の可視化**: 文法構造を視覚的に理解しやすく表示します。

### 2. 🗣️ 高度な読み上げ機能 (Text-to-Speech)
- **リアルタイムハイライト**: 読み上げている箇所をリアルタイムでハイライト表示します。
- **音声コントロール**: 再生・停止・一時停止が可能です。

### 3. 📚 インタラクティブ辞書 (Interactive Dictionary)
- **即時検索**: 単語をクリックすると、詳細な辞書情報（意味、品詞、読み方）がポップアップ表示されます。
- **アクセント表示**: 日本語学習に重要な「ピッチアクセント」を視覚的に表示します。

### 4. 💾 単語帳 & エクスポート (Vocabulary & Export)
- **ワンクリック保存**: 気になる単語を「⭐」ボタンで単語帳に保存できます。
- **Anki連携**: 保存した単語を **Anki** デッキ用フォーマット（TSV）でエクスポート可能。
- **CSV出力**: 一般的なCSV形式でのバックアップにも対応。

### 5. 🎨 カスタマイズ (Customization)
- **フォント切り替え**: 明朝体・ゴシック体など、読みやすいフォントを選択可能。
- **文字サイズ調整**: 視認性を高めるためのサイズ変更に対応。

## 🛠️ 技術スタック (Tech Stack)

このプロジェクトは最新の Web 技術を使用して構築されています。

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
- **UI Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **State Management**: [Zustand](https://github.com/pmndrs/zustand)
- **Database**: [IndexedDB (via idb)](https://github.com/jakearchibald/idb) - オフライン辞書データ用
- **NLP Engine**:
  - `kuroshiro`: 日本語テキスト変換
  - `kuromoji`: 形態素解析器
- **Icons**: [Lucide React](https://lucide.dev/)
