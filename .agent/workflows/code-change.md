# 代码修改强制验证流程

> ⚠️ **重要**: 任何对 src/ 目录下文件的修改都必须完整执行此流程。验证失败必须修复后重新验证，直到全部通过才能通知用户。

## 验证步骤

// turbo-all

### 1. TypeScript 类型检查
```bash
npx tsc --noEmit
```
- 必须 0 错误才能继续
- 如有错误，立即修复并重新执行此步骤

### 2. ESLint 语法检查
```bash
npm run lint
```
- 必须 0 错误才能继续
- 警告(warning)可以接受，但错误(error)必须修复

### 3. Next.js 构建测试
```bash
npm run build
```
- 必须构建成功才能交付
- 构建失败必须修复

## 验证失败处理

如果任何步骤失败：
1. **不要通知用户**
2. 分析错误信息，定位问题
3. 修复代码
4. 从步骤1重新开始验证
5. 只有全部通过后才能使用 notify_user 通知用户

## 交付标准

✅ TypeScript: 0 errors
✅ ESLint: 0 errors (warnings 可接受)
✅ Build: 成功

只有满足以上全部条件，才能告知用户任务完成。
